# IA Descomplicada

Portal educativo estático sobre inteligência artificial. Projeto de TCC do curso Técnico em Informática para Internet (SENAI).

## Como executar
Abra o arquivo `index.html` em qualquer navegador moderno. Não é preciso servidor nem internet.

## Estrutura
```
IA-Descomplicada/
├── index.html
├── css/style.css
├── js/script.js
├── assets/images/
├── assets/icons/favicon.svg
└── README.md
```

## Tecnologias
HTML5 semântico, CSS3 e JavaScript puro (sem frameworks, back-end ou banco de dados).

## Funcionalidades
Menu responsivo, tema claro/escuro, linha do tempo, abas, cards de ferramentas com filtro, glossário com busca, perguntas frequentes em sanfona, quiz de 10 perguntas, botão de voltar ao topo e animação ao rolar (respeita a preferência por redução de movimento).

## Observações
Links de fontes e de ferramentas devem ser conferidos antes da apresentação, pois sites mudam. Planos e recursos das ferramentas não são descritos de propósito.
